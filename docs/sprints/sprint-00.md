# Sprint 00 — Project Foundation

## Objetivo

Preparar la base técnica y documental del proyecto TaskFlow.

## Alcance

- Crear repositorio Git.
- Definir arquitectura inicial.
- Definir stack tecnológico.
- Crear frontend Angular.
- Crear backend Spring Boot.
- Configurar PostgreSQL.
- Verificar comunicación entre las capas.

## Arquitectura

Angular
↓
REST API
↓
Spring Boot
↓
JPA / Hibernate
↓
PostgreSQL

## Definition of Done

El Sprint se considera terminado cuando:

- Angular ejecuta correctamente.
- Spring Boot ejecuta correctamente.
- PostgreSQL está disponible.
- Spring Boot se conecta a PostgreSQL.
- El proyecto está versionado con Git.
- Existe documentación inicial.
